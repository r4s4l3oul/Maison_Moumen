# Caftan Moumen — Socle HTML/CSS/JS natif

Ce projet a été réinitialisé pour utiliser uniquement du HTML, CSS et JavaScript natifs.

## Structure du projet

- `index.html` — page principale
- `styles.css` — styles globaux
- `app.js` — logique JavaScript côté client

## Développement

Ouvrez `index.html` dans votre navigateur ou servez le dossier depuis un serveur HTTP local.
